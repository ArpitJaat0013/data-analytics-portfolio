# Google Colab

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/ArpitJaat0013/data-analytics-portfolio/blob/main/notebooks/colab/environment-check.ipynb)

`environment-check.ipynb` verifies that a Colab runtime has pandas, numpy, matplotlib and seaborn available.

Colab is reachable at <https://colab.research.google.com>. Sign in with a Google account to save notebooks to your own Drive; a runtime can be connected and code executed even before signing in.
