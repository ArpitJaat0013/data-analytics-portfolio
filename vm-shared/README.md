# VM shared folder (UTM WebDAV)

This folder is intended to be shared with the Windows 11 ARM UTM VM for Power BI / Power Query work.

- `datasets/`  — place CSV/Excel/Parquet and other source files here (inputs for Power BI).
- `exports/`   — save reports/exports/output files back here from the VM.

Shared via UTM **Settings → Sharing** (SPICE WebDAV). The VM is disposable; keep source data and outputs in this repo/workspace folder on macOS.
